# Timezones

[![made with an LLM](https://img.shields.io/badge/made_with-an_LLM-blue)](https://shields.io)

A world clock and timezone converter in a single file.

Pick a **base** timezone plus a date and time, and every location
you add shows two things: its **live current time**, and **what time it
is there at the moment you picked** — with the local date, a day-shift
badge when the day is different, and a marker while daylight saving is
in effect. Plan a meeting across timezones, or just keep track of home
and everywhere else.

There is no account and no server: the app is one self-contained HTML
file, it works offline, and everything you set up is saved in your
browser.

**How it was made** — the app (`index.html`), the illustrated guide
(`help.html`), and this README were generated by an LLM (qwen3.8-27b)
in an interactive, human-directed session.

## Getting started

There is nothing to install.

1. Download **`index.html`** from this repository (and **`help.html`**
   too, if you want the illustrated guide).
2. Double-click the file to open it in any modern browser — Chrome,
   Edge, Firefox, or Safari. That's it.

Prefer a URL? Put the files in a folder and serve it with any static
file server, for example:

```
python3 -m http.server 8000
```

then visit <http://localhost:8000>.

## A quick tour

- **Base timezone** — type a city, an IANA zone (`Europe/London`), or a
  UTC offset (`+05:30`) and pick a suggestion. A place you already
  display is pickable too: it becomes the base, and its card stays.
- **Date & time** — the moment you want to convert; use the calendar
  icon or the **Now** button.
- **Add a location** — as many as you like; each gets a card with its
  live clock and the converted time. Drag cards to reorder them, and
  **×** removes one. Your base is addable here too — a place may be
  both base and a location.
- **?** — opens the illustrated help page, with diagrams of every
  control and card part.
- **Export / Import** — in the footer: back up your whole setup to a
  JSON file (and restore it, e.g. after clearing your browser storage).
- Dark/light theme and 12/24-hour display — your choices are
  remembered. **Reset** in the footer restores the first-run setup.
